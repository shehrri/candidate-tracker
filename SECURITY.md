# Security

Candidate Tracker stores confidential recruiting records in the browser profile.
It does not provide authentication or application-level encryption. Read the
README and BACKUP-GUIDE before handling personal information.

## Reporting a concern

Do not include real candidate information, backups, credentials, or exploitable
vulnerability details in public issues or pull requests. If GitHub's private
"Report a vulnerability" option is available under this repository's Security
tab, use it. Otherwise, request a private contact channel from the maintainer
without disclosing vulnerability details in the public request.

Provide the affected version, browser/OS, a description of the impact, and steps
using synthetic data through the agreed private channel. There is no guaranteed
response time or paid support commitment.

## Current scope

This project is in its initial release cycle. Windows testing is owner-confirmed, and the dependency audit is clean as of
November 5, 2026; see TEST-REPORT.md for scope and remaining platform checks.
Users should keep protected backups, use a trusted browser profile and OS account,
and avoid opening untrusted downloaded resumes without normal document safeguards.
